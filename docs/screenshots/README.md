## Cómo tomar las capturas desde Android Studio

1. Correr la app en el emulador (`Shift + F10`)
2. En la barra lateral del emulador, clic en el ícono de cámara (screenshot)
3. O desde el Device Manager: **⋮ → Take Screenshot**
4. Guardar con el nombre exacto de la tabla de arriba en esta carpeta
5. Hacer commit de todas las imágenes junto con el README
